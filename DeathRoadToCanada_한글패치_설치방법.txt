Death Road to Canada 비공식 한글패치 설치 방법
==================================================

이 안내문은 Windows용 Steam 정품 Death Road to Canada를 기준으로 합니다.
지원 게임 빌드: 24936165
게임 업데이트 후에는 설치가 안 될 수 있습니다. 설치 전 게임을 완전히 종료하세요.

[1. 준비물]

1) Steam 정품 Death Road to Canada
2) Windows용 Python 3.10 이상
   다운로드: https://www.python.org/downloads/windows/
   설치 첫 화면에서 'Add python.exe to PATH'를 체크한 뒤 설치하세요.
3) DRTC-Korean-Patch-main.zip
   한글패치 GitHub 저장소에서 Code → Download ZIP을 눌러 받은 뒤 압축을 푸세요.
   압축을 푼 폴더 안에 install.py, uninstall.py, requirements.txt가 보여야 합니다.
   예: C:\DRTC-KO\DRTC-Korean-Patch-main
4) Mod Loader V202.0
   배포 페이지: https://arkwright1.blog.fc2.com/blog-entry-1576.html
   직접 다운로드해서 압축을 푸세요. 제3자 제작자의 파일이므로 한글패치와 함께 재배포하지 마세요.
   로더는 게임 폴더 바깥에 두세요. 예: C:\DRTC-Loader\1.MOD LOADER
   지정할 로더 폴더를 열었을 때 dr2c-gadget.dll 파일과 mods 폴더가 바로 보여야 합니다.
   배포본에 prog_Patch.exe가 있다면 직접 실행하지 마세요.

[2. 게임 폴더 찾기]

1) Steam 라이브러리에서 Death Road to Canada를 마우스 오른쪽 클릭합니다.
2) 관리 → 로컬 파일 보기를 누릅니다.
3) 열린 폴더에 prog.exe가 바로 들어 있는지 확인합니다. 그 폴더가 게임 폴더입니다.
   예시 경로는 아래와 같지만, 반드시 본인 PC에서 실제로 열린 경로를 사용하세요.
   C:\Program Files (x86)\Steam\steamapps\common\Death Road to Canada

[3. PowerShell 열기]

1) install.py가 보이는 한글패치 폴더를 파일 탐색기로 엽니다.
2) 탐색기 위쪽 주소창을 클릭하고 powershell이라고 입력한 뒤 Enter를 누릅니다.
3) 열린 PowerShell 창에 아래 명령어를 하나씩 붙여넣어 실행합니다.

[4. 필요한 Python 패키지 설치 — 처음 한 번]

python -m pip install -r requirements.txt

설치가 끝나면 다음 단계로 진행합니다. 'python'을 찾을 수 없다는 오류가 나오면
Python 설치 때 'Add python.exe to PATH'를 체크했는지 확인하세요.

[5. 설치 전 검사 — 게임 파일은 변경되지 않음]

아래 명령어 예시에서 게임 경로와 로더 경로를 실제 경로로 바꿔 주세요.
큰따옴표는 유지해야 합니다. 아래 경로는 예시입니다.

python install.py --game-root "C:\Program Files (x86)\Steam\steamapps\common\Death Road to Canada" --loader-root "C:\DRTC-Loader\1.MOD LOADER" --check

검사가 성공하고 ERROR가 표시되지 않으면 실제 설치를 진행합니다.
ERROR가 표시되면 설치하지 말고 오류 메시지부터 확인하세요.

[6. 한글패치 설치]

5번에서 사용한 명령어의 맨 끝 --check를 --apply로 바꿔 실행합니다.

python install.py --game-root "C:\Program Files (x86)\Steam\steamapps\common\Death Road to Canada" --loader-root "C:\DRTC-Loader\1.MOD LOADER" --apply

게임 경로와 로더 경로는 꼭 본인 PC에 맞게 바꿔야 합니다.
설치 프로그램은 먼저 게임 폴더를 백업한 다음 한글패치를 적용합니다.
백업 폴더는 일반적으로 게임 폴더 옆에 Death Road to Canada_KO_backup_날짜 형식으로 만들어집니다.
백업 폴더와 설치 기록 파일은 문제 해결에 필요하므로 바로 삭제하지 마세요.
설치가 끝나면 Steam에서 평소처럼 게임을 실행하세요.

[7. 한글패치 제거]

게임을 완전히 종료한 뒤 한글패치 폴더에서 PowerShell을 엽니다.
아래 명령어의 '게임 폴더'를 실제 경로로 바꾸고 큰따옴표를 유지하세요.

먼저 제거 전 검사:
python uninstall.py --game-root "게임 폴더" --check

검사가 성공하면 실제 제거:
python uninstall.py --game-root "게임 폴더" --apply

제거 후 게임이 정상적으로 실행되는지 확인한 뒤, 문제가 없을 때 백업을 정리하세요.

[8. 자주 발생하는 오류]

• 'python'을 찾을 수 없음: Python 설치 시 Add python.exe to PATH 옵션을 확인하세요.
• 'No module named polib' 또는 'PIL': 4번의 패키지 설치 명령을 다시 실행하세요.
• 'game root must be the folder containing prog.exe': 게임 폴더 경로가 잘못됐습니다.
• 'Loader SHA-256 mismatch or missing file': 로더가 호환 버전인지 확인하고,
  --loader-root 경로 바로 안에 dr2c-gadget.dll과 mods 폴더가 있는지 확인하세요.
  이 패치는 호환되는 Mod Loader V202.0을 요구합니다.
• 'Unsupported prog.exe SHA-256' 또는 'Unsupported/modified English script':
  게임 빌드가 지원 버전과 다르거나 게임 파일이 수정되었을 수 있습니다.
  Steam → 게임 속성 → 설치된 파일 → 게임 파일 무결성 검사를 실행한 뒤 다시 확인하세요.
• 게임이 실행 중이라는 오류: 게임을 완전히 종료한 뒤 다시 검사하세요.
